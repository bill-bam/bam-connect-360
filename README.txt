BAM.Connect 360 BMW Interactive Demo

This builds on the existing Render v7 backend without changing CarHub API logic.

TO DEPLOY ON EXISTING RENDER SITE:
1. Upload server.py, bmw-viewer.html and bmw-viewer.mp4 to the ROOT of github.com/bill-bam/bam-connect-360, replacing server.py. Do not upload the ZIP itself.
2. Commit. Wait for Render deployment to say Live.
3. Open https://bam-connect-360-trial.onrender.com/bmw-viewer

OFFLINE: bmw-viewer.html and bmw-viewer.mp4 in the same directory; double click HTML.

NOTE: the BMW preview is publicly reachable by anyone who knows the URL. Never include API keys in GitHub.
